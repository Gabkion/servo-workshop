2. Δοκιμή κώδικα

Αντιγράψτε τον κώδικα στο Arduino IDE και δοκιμάστε τον.

Arduino Sketch (.ino) 
#include <Servo.h>

Servo myServo;

void setup() {
  myServo.attach(9); // Συνδέουμε το servo στο Pin 9
}

void loop() {
  myServo.write(45);   // Θέση 1
  delay(1000);

  myServo.write(135);  // Θέση 2
  delay(1000);
}
Σημείωση: Καλό είναι να πατάτε αποδέσμευση πριν το Upload στο Arduino IDE, ώστε να μην μπλοκάρεται η σειριακή θύρα.

3. Σειριακός Έλεγχος (Serial Control)

Κώδικας Arduino για ανάγνωση σειριακών εντολών από τον υπολογιστή και κίνηση στις αντίστοιχες θέσεις.

Arduino Sketch (.ino) 
#include <Servo.h>

Servo myServo;

void setup() {
  Serial.begin(9600);
  myServo.attach(9);
  myServo.write(90);   // Αρχική θέση (κέντρο)
}

void loop() {
  if (Serial.available() > 0) {
    char command = Serial.read();

    if (command == '1') {
      myServo.write(45);  // Θέση 1 (45°)
    } 
    else if (command == '2') {
      myServo.write(135); // Θέση 2 (135°)
    }
  }
}
Σημείωση: Καλό είναι να πατάτε αποδέσμευση πριν το Upload στο Arduino IDE, ώστε να μην μπλοκάρεται η σειριακή θύρα.
  1. Ανεβάστε τον κώδικα στο Arduino Leonardo μέσω του Arduino IDE.
  2. Ανοίξτε το Serial Monitor (9600 baud) ή συνδεθείτε απευθείας από τη σελίδα.
  3. Στείλτε '1' για 45° ή '2' για 135°.
