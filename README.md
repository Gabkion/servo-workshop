# Servo Workshop

Εκπαιδευτική ιστοσελίδα για το εργαστήριο ελέγχου σερβοκινητήρα (SG90) με Arduino Leonardo (ATmega32U4) μέσω WebSerial.

## Χρήση

1. Συνδέστε το Arduino Leonardo στον υπολογιστή σας μέσω USB.
2. Ανοίξτε το Arduino IDE και φορτώστε το sketch `firmware/all_in_one_tester.ino` στο Arduino Leonardo.
3. Πηγαίνετε στην ιστοσελίδα του ([Servo Workshop](https://gabkion.github.io/servo-workshop/)) και κάντε κλικ στο κουμπί "CONNECT ARDUINO" για να συνδεθείτε με το Arduino μέσω WebSerial.
4. Επιλέξτε το Arduino Leonardo από τη λίστα συσκευών.
5. Ακολουθήστε τις οδηγίες στην ιστοσελίδα για να εκτελέσετε την άσκηση.
